# AWS Cloud Practitioner — Learning & Revision Guide

An independent learning resource for understanding Amazon Web Services (AWS), strengthening cloud fundamentals, and preparing for the AWS Certified Cloud Practitioner (CLF-C02) certification.

This repository contains original notes, practical examples, service comparisons, revision summaries, and practice questions designed to make AWS concepts easier to understand and apply.

## Objectives

- Build a strong foundation in cloud computing and AWS.
- Understand the purpose and use cases of AWS services.
- Learn essential cloud security and cost-management principles.
- Compare AWS services and identify appropriate use cases.
- Strengthen conceptual understanding through scenario-based questions.
- Maintain concise revision notes for certification preparation.

## Repository Structure

Each learning area will contain three focused resources:

- `concepts.md` — Core concepts, service features, use cases, and comparisons.
- `exam-questions.md` — Original practice questions with answers and explanations.
- `quick-revision.md` — Key takeaways, comparison tables, and exam reminders.

## How to Use This Repository

1. Start with the relevant cloud concept.
2. Understand the AWS services associated with it.
3. Review practical examples and comparisons.
4. Attempt practice questions without checking the answers first.
5. Read the explanations and revisit weak areas.
6. Use the quick-revision notes for periodic review.

## Certification Preparation
