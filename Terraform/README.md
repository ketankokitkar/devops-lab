# Terraform Lab

This repository contains my hands-on learning and practical implementation of Terraform, with a focus on AWS infrastructure and real-world Terraform workflows.

## Terraform Learning Path

| Day | Topic | Focus |
|---|---|---|
| 01 | Terraform Fundamentals | IaC, Terraform basics, AWS provider, EC2 creation, lifecycle and state |
| 02 | Terraform Configuration | Providers, resources, variables, outputs, functions and expressions |
| 03 | Terraform Modules | Modules, locals, data sources, inputs, outputs and reusable infrastructure |
| 04 | State and Collaboration | Git, sensitive data, remote state, S3 backend and state locking |
| 05 | Terraform Provisioners | Provisioners, remote-exec, local-exec and provisioning workflows |
| 06 | Terraform Workspaces | Managing multiple environments using Terraform workspaces |
| 07 | Terraform Security and Vault | Secrets management and Terraform integration with Vault |
| 08 | Migration and Drift Detection | Migrating existing infrastructure and detecting infrastructure drift |
